Daily summary (GitHub Actions)

A GitHub Action writes a summary every day at 07:00 UTC, but it cannot see this browser. It summarises the file data/snapshot.json in the repository. To update it: click the button, save the file over data/snapshot.json, then commit and push it.

Commit fake data only. The snapshot contains everything stored in this browser, and the repository and the website are public. If you typed a real name or email into the enquiry form, clear it first.
